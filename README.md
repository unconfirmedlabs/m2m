# m2m

Economic coordination for autonomous software, using **Iroh for transport** and
**Sui for economic programmability**.

The project is in positioning and proof-of-concept scoping. Its proposed role is
to connect authenticated peers, scoped authority, agreed work, and economic
outcomes across these two layers. The proposed technical experiment is a paid
service exchange over Iroh with a buyer-acceptance escrow on Sui testnet.
The first real service and customer workflow remain open.

Start with the [positioning and problem definition](docs/POSITIONING.md), then
read the [north star](docs/NORTH_STAR.md) and the
[agent protocol research](docs/research/AGENT_PROTOCOLS.md).

The [proposed PoC scope](docs/POC_SCOPE.md) defines the exchange, trust assumptions,
deliverables, failure cases, and acceptance criteria. Implementation has not begun.

[AGENTS.md](AGENTS.md) contains concise working guidance for contributors and
coding agents. The research is a dated reference; the north star should evolve
with evidence and explicit project decisions.
